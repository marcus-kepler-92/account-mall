很多人买了美区 Apple ID，在 App Store 里搜到 Shadowrocket（小火箭）后发现要付费，而不是「获取」。这不是账号有问题。

## 为什么要付费

小火箭是美区 App Store 上的**付费 App**，价格以 App Store 显示为准。App 的购买记录是跟着 Apple ID 走的：

- **这个账号买过**：显示云朵下载图标，可以免费重复下载。
- **这个账号没买过**：显示价格，需要付款。

新注册的美区账号，或者普通的独享账号，都没有买过小火箭，所以会显示价格。

## 常见问题

### 小火箭提示需要输入其他账号密码才能更新

苹果规定：用哪个 Apple ID 下载的 App，就要用哪个 Apple ID 更新。用共享账号下载的小火箭，更新时也要登录同一个账号。如果那个账号已经登录不上，需要换一个买过小火箭的账号重新下载，可以直接[再买一个已购小火箭账号](/products/apple-id-shadowrocket)。
