很多人买了美区 Apple ID，在 App Store 里搜到 Shadowrocket（小火箭）后发现要付费，而不是「获取」。这不是账号有问题。

## 为什么要付费

小火箭是美区 App Store 上的**付费 App**，价格以 App Store 显示为准。App 的购买记录是跟着 Apple ID 走的：

- **这个账号买过**：显示云朵下载图标，可以免费重复下载。
- **这个账号没买过**：显示价格，需要付款。

新注册的美区账号，或者普通的独享账号，都没有买过小火箭，所以会显示价格。

## 方法一：用已购小火箭的共享账号下载

[已购小火箭的共享账号](/products/apple-id-shadowrocket)已经买过 Shadowrocket，登录后就能直接下载，不用自己付费，适合只想尽快装上小火箭的情况。

1. 打开桌面上的 **App Store** → 点右上角头像 → 拉到最下面点「退出登录」。**不要在「设置」里登录。**
2. 再点右上角头像，复制粘贴账号和密码登录。
3. 如果弹出「Apple ID 安全性」，点「其他选项」→「不要升级」。
4. 回到首页，搜索 Shadowrocket，点云朵图标下载。
5. 下载完成后可以退出账号，小火箭会留在你的手机上。

## 常见问题

### 小火箭提示需要输入其他账号密码才能更新

苹果规定：用哪个 Apple ID 下载的 App，就要用哪个 Apple ID 更新。用共享账号下载的小火箭，更新时也要登录同一个账号。如果那个账号已经登录不上，可以删掉小火箭，用当前能登录、并且买过小火箭的账号重新下载。删除前记得先导出配置。

### 登录提示「账号或密码错误」

请直接复制粘贴，不要手动输入，并检查前后有没有多出空格。

### 一直转圈或提示无法登录

开关一次飞行模式、在 Wi-Fi 和移动数据之间切换，或者把 DNS 改成 4.2.2.2 和 4.2.2.1，再重启手机试试。
