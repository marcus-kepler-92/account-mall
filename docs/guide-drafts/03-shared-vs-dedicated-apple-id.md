买外区 Apple ID 时最常见的两个问题是：共享号和独享号有什么区别？会不会把手机锁住？先说结论：**只要只在 App Store 里登录外区账号，手机就不会被锁。**

## 共享和独享的区别

| 对比项 | 共享账号 | 独享账号 |
|---|---|---|
| 使用人数 | 多人同时使用 | 只有你一个人 |
| 密码 | 可能随时被改 | 交付后由你自己修改，固定不变 |
| 地区 | 部分共享号是随机地区 | 按需选择 |
| 能否改密码、绑邮箱 | 不能 | 可以，改完账号就归你 |
| 更新 App | 账号可能已失效，不方便更新 | 随时可以更新 |
| 适合 | 临时下载一次 | 长期使用 |

## 锁机是怎么发生的

「锁机」通常是指手机进入激活锁，或者 iCloud 被别人控制。只有在下面两种情况下，外区账号才可能影响到你的手机：

1. **在「设置」最上方或 iCloud 里登录了外区账号**。这样会把账号绑定到这台设备上，开启「查找」后，账号主人或其他共享者就可能远程锁定设备。
2. **给共享账号开启了双重认证，或者绑定了自己的手机号**。别人改了账号信息后，你可能会收到大量验证码短信，甚至无法退出账号。

只在 App Store 里登录时，账号只用于下载 App，不会同步 iCloud，也不会开启「查找」，所以不存在锁机风险。

## 记住一条原则

**外区账号只在桌面的 App Store 里登录，手机「设置」最上方始终保持登录你自己的 Apple ID。** 共享账号也不要开启双重认证，不要绑定自己的手机号。

登录过程中可能会弹出安全性升级、双重认证等提示，每个提示该怎么选会影响账号安全。本站的账号发货时会附上图解登录教程，按教程操作即可；遇到教程里没有的情况，请先联系客服，不要自己乱点。
