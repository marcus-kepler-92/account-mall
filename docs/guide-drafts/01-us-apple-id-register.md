注册美区 Apple ID 不需要美国手机号，也不需要美国信用卡。整个过程分两步：先在网页上创建账户，再到 iPhone 的 App Store 里登录并补全资料。

> 苹果从 iOS 18 起把「Apple ID」改名为「Apple 账户」，两者是同一个东西，下文统一称 Apple ID。

## 注册前准备

- **一个没注册过 Apple ID 的邮箱**：Gmail、Outlook、QQ 邮箱都可以，建议用以后不会弃用的邮箱。
- **一个能收短信的手机号**：国内手机号一般就可以收验证码，用于双重认证。
- **一个格式正确的美国地址**：街道、城市、州和邮编要对得上。常见做法是选不收消费税的州，例如俄勒冈（Oregon）或特拉华（Delaware）。

## 第一步：在网页上创建账户

1. 用浏览器打开 account.apple.com，点击「创建你的 Apple 账户」。
2. **「国家或地区」选「美国」**。这一项决定了账号所属的 App Store 地区，注册后再改会麻烦很多。
3. 填写姓名、出生日期（需年满 18 周岁）、邮箱和密码。
4. 填写手机号，选择用短信接收验证码。
5. 分别输入邮箱和手机收到的验证码，账户就创建好了。

## 第二步：首次登录 App Store，补全资料

网页注册的账号还不能直接下载 App，需要先在设备上补全付款信息。

1. 打开桌面上的 **App Store** 图标，点右上角头像，用新账号登录。**不要在「设置」最上方登录**，那里登录会同步 iCloud、通讯录等数据。
2. 系统会提示「此 Apple 账户尚未在 App Store 中使用过」，点「检查」。
3. 打开「同意条款与条件」，点「下一步」。
4. **付款方式选「无」（None）**。
5. 账单地址填写准备好的美国地址，电话号码可以填美国格式的号码。
6. 点「下一步」完成，账号就可以在美区 App Store 下载免费 App 了。

> 如果付款方式里没有「无」，可以先退出，在 App Store 里随便找一个免费 App 点「获取」，用新账号登录时会再次进入补全资料页面，这时通常会出现「无」。

## 常见报错与处理

### 提示「目前无法创建你的账户」

- 苹果对同一台设备每年可以新建的账户数量有限制，换一台设备或改用网页注册再试。
- 网络环境也可能触发风控，切换 Wi-Fi 和移动数据后再试。
- 同一个邮箱或手机号短时间内反复尝试也会被拦截，隔一天再试。

### 登录时弹出「Apple ID 安全性」

这是苹果在提示你升级双重认证。如果只是用来下载 App，点「其他选项」→「不要升级」即可跳过。

### 提示「此 Apple ID 尚未在 iTunes Store 使用过」后卡住

一般是网络问题。开关一次飞行模式，或者把 DNS 改成 4.2.2.2 和 4.2.2.1，再重新登录。

### 下载付费 App 或订阅时提示没有付款方式

付款方式选了「无」的账号只能下载免费 App。要买付费 App 或订阅，可以给账号充值[美国 Apple 礼品卡](/products/apple-gift-card-us)，兑换后余额会直接用于扣款。

## 已有国区账号，能不能直接改成美区？

可以，但条件比较多：账户余额必须用完、所有订阅要取消并等到期、退出家庭共享，还要提供新地区的付款方式。如果国区账号里有购买记录和订阅，建议保留它，另外注册一个美区账号专门用于下载。

## 不想自己注册？

如果多次注册失败，或者只是想马上下载美区 App，也可以直接购买[美区 Apple ID 独享账号](/products/apple-id-us)。账号只给你一个人用，收到后可以自己修改密码、密保和绑定邮箱，付款后自动发货。
